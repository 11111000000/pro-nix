# Glossary

> Hand-maintained. Terms the project uses in a specific way that is not obvious
> from reading the code. Not a Nix or Emacs glossary — for those, follow the
> upstream docs.

## A

**Aporetic** — Family of bitmap fonts the project ships (`Aporetic Sans`,
`Aporetic Sans Mono`). Default for `pro-ui-{code,text}-font-family` and
`conf/fonts.conf`. Falls back to DejaVu if not in the system closure.

**agent** — A CLI tool that wraps an LLM with a tool-use protocol. The project
uses `pi` (lukasl-dev) and `opencode` (npm-binary). Both are configured
through `local-templates/{pi,opencode}/` and deployed by
`pro-agent-configs.nix`.

**agent-shell** — An Emacs package (submodule `11111000000/agent-shell`) that
turns Emacs into a chat UI for ACP-speaking agents. Adapted by
`pro-agent-shell.el`.

**ACP** — Agent Client Protocol. The JSON-RPC protocol that `agent-shell`
speaks to backends. Implemented in `submodules/acp/` (xenodium/acp.el fork).

**autoload** — `(autoload 'name "file")` defers loading a function until first
call. pro-*.el modules use `###autoload` for interactive commands that may not
be available at load time.

## C

**Change-Gate** — The four-field format at the top of every PR body:
`Intent:`, `Pressure:`, `Surface:`, `Proof:`. Enforced by
`actions/check-change-gate/action.sh`.

**composition** — A `hosts/<name>/composition.nix` file. Imports
`system-package-sets-*` and `++`s them into `environment.systemPackages`. A
composition is **not** a NixOS module — it is a plain Nix expression that
returns an attrset.

**contract test** — A test in `tests/contract/*` that asserts a structural
property of the configuration. The five contract tests currently cover the
network layer (`pro-network-01.sh`), peer module (`pro-peer-01.sh`), tor
(`tor-01.sh`), surface headers (`surface-headers.sh`), and the docker dev
chain (`test_docker_dev.sh`).

**CUDA compat** — `nix-cuda-compat.nix` adds `types.atom` to the formats
infrastructure and a `cudaPackages.{cudaFlags, cudaVersion}` shim. It is
loaded through `flake.nix#pkgsOverlay`, so every host sees it.

## D

**defcustom** — The Emacs mechanism for a user-facing setting. pro-*.el modules
expose ~70 defcustoms across 22 `defgroup`s. The catalogue is at
[Reference → defcustom knobs](reference/defcustom.md).

**defgroup** — A logical grouping for `defcustom` and `defface`. The project
uses groups like `pro`, `pro-ui`, `pro-ui-theme`, `pro-ui-modeline`,
`pro-history`, `pro-buffer-banner`, `pro-docker`, `pro-emcp`, `pro-exwm`,
`pro/chat`, `pro/chat-telega`, `pro-tabs`, `pro-profiler`, `pro-spell`,
`pro-windows`, `pro-completion`, etc.

**DERP** — Tailscale's relay protocol. Headscale can serve a DERP map; in
`modules/headscale.nix` it is disabled by default
(`derp.server.enabled = false`).

**devShell** — `flake.nix#devShells.x86_64-linux.default`. Provides Emacs with
~25 emacsPackages on `EMACSLOADPATH`, plus `ripgrep`, `fd`, `findutils`,
`stress-ng`, `fio`, `powertop`, `iotop`, `lm_sensors`, `time`, `shellcheck`,
`direnv`, `gh`. A wrapper script at `$PWD/.pro-emacs-wrapper/emacs-pro` is
created on `nix develop` with `-L <pkg>/share/emacs/site-lisp` flags for every
overlay-provided package.

## E

**EMCP** — Emacs MCP. The HTTP MCP server that lives at
`http://127.0.0.1:38913/mcp`. Implemented in the `emcp` submodule (codeberg
`martenlienen/emcp`), backed by `http-server.el` (also a fork by the same
author). The Emacs side is wrapped by `pro-emcp.el` with four defcustoms
(`port`, `host`, `profile` ∈ {`inspect`, `develop`, `full-control`},
`auto-start`) and five commands (`start`, `stop`, `restart`, `status`, `url`).

**EXWM** — Emacs X Window Manager. EXWM is the canonical WM in pro-nix — the
`~/.config/pro/exwm-session` script (generated by `emacs/exwm.nix:96-176`)
launches Emacs under `systemd-run --user --scope` with resource limits and
IME env vars.

**exwm-xim** — The X Input Method bridge in EXWM. Set via
`XMODIFIERS=@im=exwm-xim` in the session launcher. **Not** related to Emacs
key-simulation (that is `exwm-input-simulation-keys` in `pro-exwm-sim.el`).

## F

**FROZEN** — A surface marker on a `Change-Gate` PR body that says: any
change to this surface needs a migration note. Used for public NixOS options
that downstream users (or future me) may depend on.

**FLUID** — The opposite: a surface that is still in flux, can change without
a migration note.

## G

**GCM** — Guarded Configuration Modules. Pattern used in `conf/exwm.nix` and
`emacs/exwm.nix` where `pro-compat--add-hook-once`,
`pro-compat--add-to-list-once`, `pro-compat--advice-add-once` ensure top-level
forms are idempotent under soft-reload.

**guix** — `services.guix.enable = true` is set globally; pro-nix keeps Guix
as a fallback package manager for cases where a binary is not in nixpkgs.

## H

**headscale** — Self-hosted Tailscale control-plane. Implemented in
`modules/headscale.nix` with a YAML config that follows the upstream
`headscale` 0.27+ schema. The role `headscale` is assigned to exactly one
host — `desktop` — and `lib.mkForce false` on all others.

**holo-verify** — `tools/holo-verify.sh` is the top-level verification driver.
Modes: `unit`/`--quick` (default), `elisp`, `nixos-fast`, `full`. Reports
whether `HOLO.md` test references are real.

**HOLO.md** — A "frozen" document that lists invariants the system must
uphold. Not in the current source tree (the file is referenced in PR
templates); to be created.

**HUD** — In `agent-shell-hud` (submodule `11111000000/agent-shell-hud`), a
multilingual heads-up display (model + token usage + permissions). Binds to
`C-c a` (menu), `C-c i` (info), `C-c r` (refresh) inside `agent-shell-mode`.

## I

**icp** — Identity Control Plane. Not in this project; mentioned here only
because "icp" sometimes appears in headscale Tailscale docs.

**imc** — `systemd --user import-environment`. Called from
`~/.local/bin/pro-emacs-env-fix.sh` (autostart) and from the EXWM session
launcher to ensure `DISPLAY`, `XAUTHORITY`, `DBUS_SESSION_BUS_ADDRESS`,
`XDG_CURRENT_DESKTOP` reach Emacs under `systemd-run`.

## M

**MagicDNS** — Tailscale's internal DNS resolver. The
`pro-ssh-clients.nix`-generated `ssh_config.d/pro.conf` puts the MagicDNS
FQDN first in the candidate list so the SSH connection lands on the right
host even when LAN mDNS is down.

**mkDefault** — A priority marker on a NixOS option, default 100. Allows
other modules to override without conflict. **Anti-pattern:** using it for
mandatory `environment.systemPackages` (plain assignment is mandatory;
mkDefault is for defaults).

**mkForce** — Priority 50, wins over plain and `mkDefault`. Used in
`hosts/*/configuration.nix` to deliberately override what global modules
gave. The `cf19`/`huawei` `headscale.enable = lib.mkForce false` is the
canonical example.

**mkVmHost** — A second host constructor in `flake.nix:92-102`. Does NOT
import `configuration.nix`. Used for `vm` to keep the eval minimal and
avoid pulling in `headscale.nix` (which would otherwise add options that
are not meaningful in the VM context).

**Mole** — In Emacs terminology: a mode + a role pair (e.g. `pro-c-mole`,
`pro-python-mole`). pro-nix does not use the term heavily but `pro-c.el`,
`pro-python.el`, etc., each have a "set up the mole on `xxx-mode-hook`"
contract.

## N

**NSP** — NSS plugin. The `nss-mdns` package is the NSP for `.local` mDNS
resolution on glibc systems. Without it, `getent hosts <name>.local`
returns empty even when Avahi is publishing the name.

## O

**opencode** — The second AI agent, an npm binary. The `opencode-stub.nix`
overlay downloads the tarball and patchelf's it for glibc. The bwrap'd
variant is wired through `opencodeBwrap.homeManagerModules.default`.

**overlay** — A function `(final: prev: { ... })` that patches the package
set. Five overlays: `emacs-extra`, `opencode-stub`, `pi-acp`, `mirrors`,
`github-proxy`. Applied through `flake.nix#pkgsOverlay`.

## P

**pending binding** — A global key that references a command from a package
that is not yet loaded. `pro-keys-pending-bindings` keeps it; when the
package becomes available (MELPA install, Nix-provided load), the binding
is applied.

**pi** — The primary CLI coding agent. `lukasl-dev/pi.nix` provides the
NixOS module (`pi.nixosModules.default`), wired in globally. `pi` is
launched as `pi-acp` (svkozak/pi-acp v0.0.27) for ACP communication.

**pi-crew** — A multi-agent orchestration npm package that pro-nix does
**not** install (it is excluded from `local-templates/pi/settings.json`).

**pro-** — Project prefix. Used for both NixOS modules (`modules/pro-*.nix`)
and Emacs modules (`emacs/base/modules/pro-*.el`). The prefix is
*informative*: `pro-` files are owned by pro-nix, not upstream packages.

**providedPackages** — A list of Emacs package names (60+) that Nix
**provides** in the closure. Stored in `emacs/core.nix#pro.emacs.providedPackages`
and made visible to Emacs through `EMACSLOADPATH`.

## R

**recipe** — A `nix/emacs-recipes/*.nix` file. Each is a `stdenv.mkDerivation`
that builds one Emacs package from a submodule or an external source. The
overlays pull the recipes in via `emacsPackages.elpaBuild` or
`emacsPackages.trivialBuild` equivalents.

**resolve** — `pro-ssh-clients.nix`'s per-candidate fallback: each candidate
hostname in the generated `Host` block has its own `ConnectTimeout`, so a
dead `.local` does not block a working tailnet-FQDN.

## S

**searxng** — A self-hosted metasearch engine, run by
`modules/searxng.nix`. Currently **disabled** at the top level
(`services.searxng.enable = lib.mkForce false` in `configuration.nix:85`)
because of an invalid `settings.yml` that caused a restart loop and
exacerbated boot/switch timeouts on `cf19`. TODO: fix and re-enable.

**SearXNG-secret** — The `secret_key` is generated at activation time and
written to `/var/lib/searxng/env` (chmod 0400, outside `/nix/store`).
Referenced as `EnvironmentFile` by the systemd unit. The literal `$SEARXNG_SECRET_KEY`
in the rendered `settings.yml` is expanded by SearXNG from the env file.

**shaoline** — A minimal mode-line. Submodule `11111000000/shaoline`. Set as
`pro-ui-modeline-style = 'shaoline` in `pro-ui.el`.

**SSOT** — Single Source of Truth. Three in this project: `pro.hosts`
(hosts), `emacs-keys.org` (key bindings), `local.nix` (per-host secrets).

**soft reload** — `M-x pro/reload-config` (C-x M-c) re-evaluates all loaded
modules in place. `C-u` re-evals `site-init.el` first (full reload).
Modules that own persistent state register teardown on
`pro--after-reload-hook` so a soft reload actually rebuilds their state.

**surface** — The set of public attributes a module exposes. `tools/surface-lint.sh`
enforces a five-section header (Назначение / Цель / Контракт / Побочные
эффекты / Proof) on every `modules/*.nix`.

## T

**tailscale** — The Tailscale client. `services.tailscale.enable` is
**not** set globally in this project (it requires an auth-key, which
breaks `nixos-rebuild` without a secret). Tailnet connectivity is provided
by `headscale` instead.

**tao-yang / tao-yin** — The default Emacs themes. `pro-ui-default-theme =
'tao-yang` is the default (light); the alternative is `'tao-yin` (dark).
Both come from the `tao-theme` submodule (`11111000000/tao-theme-emacs`).

**telega** — Telegram client for Emacs. Implemented in
`submodules/telega.el/` (zevlg/telega.el), with a separate TDLib-based
`telega-server` binary built by `nix/emacs-recipes/telega-server.nix`.
The Emacs side is wrapped by `pro-telega.el` and `pro-chat.el`.

**TORSOCKS** — `torsocks` wraps system calls in an LD_PRELOAD shim that
forces connections through the local SOCKS5 proxy at 9050. `bin/torwrap`
uses it (or `proxychains4` as a fallback) to run arbitrary commands
through Tor.

## W

**WAYLAND_NO_HARDWARE_CURSORS=1** — Set as `WLR_NO_HARDWARE_CURSORS=1` in
the Sway session. An Intel workaround for hardware cursors on multi-monitor
setups and after sleep.

**winner-mode** — A built-in Emacs minor mode that records window
configurations and lets you undo/redo them. Bound to `<XF86Back>` /
`<XF86Forward>` in `emacs-keys.org`.

## X

**xdg.portal** — `xdg-desktop-portal-gtk` is set as both `configPackages` and
`extraPortals` at the top level. EXWM-minimal also adds it. The `gtk`
implementation is preferred for stability over `xdg-desktop-portal-kde` or
`-gnome`.

**Xresources** — `conf/Xresources` is the single source of truth for
Emacs/URxvt/XTerm/Xmessage/Xpdf Xresources. Deployed to `/etc/X11/Xresources`
by `configuration.nix#environment.etc."X11/Xresources".text`. The `exwm-session`
merges it with `xrdb -merge` at startup so the first frame is flicker-free.

## Z

**zram** — Compressed-RAM swap. `services.zramSlice.enable` and
`size = "auto"` (50% RAM, capped 16384 MB) on `desktop` and `huawei`. Not
on `cf19` (already has swap) or `vm`.
