What is pro-nix

pro-nix is a declarative, portable NixOS + Emacs + AI-agents configuration that runs on four physical machines (desktop, cf19, huawei, vm) of one user, with no per-host manual steps after the initial just switch. It is intentionally opinionated: when there is a choice between “flexible” and “predictable”, pro-nix chooses predictable.

The codebase is a single source of truth for the system, the editor, and the agent layer. The same repo installs NixOS, configures Emacs with ~60 modules, sets up pi and opencode for AI work, brings up a private mesh via headscale, ships a tmux/Tor fallback for SSH, and serves a local search engine through SearXNG.

What pro-nix is

  • A working NixOS setup. It boots, it suspends, it survives nixos-rebuild switch.
  • An Emacs profile. Buffer banner, vertical completion, project-wide ripgrep, TUI for containers, TDLib-based Telegram, agent shells, MCP tools.
  • A network of 4 hosts that know how to find each other over LAN (<host>.local), over a private mesh (<host>.<base-domain> via headscale), and over Tor (<host>-onion through torsocks) — whichever is reachable.
  • A rule book. AGENTS.md and the per-module header comments spell out the invariants; tests/contract/* enforces them on every CI run.

What pro-nix is not

  • Not a distribution. It is one user’s environment, copy-paste friendly, but not packaged for re-distribution.
  • Not a tutorial. The repo assumes you know Nix syntax; the site explains the why and points at the where, not the how to learn Nix.
  • Not a starter template. No “fork me and rename” path. The hosts in modules/pro-hosts.nix are real, the UUIDs in hosts/*/configuration.nix are real, the layouts in conf/*-config.in are real.
  • Not a community project. It is owned, edited, and operated by one person; the public mirror exists to share the patterns, not to coordinate contributors.

The shape of the repo

configuration.nix          # top-level NixOS config
flake.nix                  # 4 hosts, 5 overlays, 17 devShell packages
modules/                   # 50+ NixOS modules + composition files
hosts/<name>/              # 4 host configs (one directory per machine)
emacs/base/                # init.el + ~60 pro-*.el modules
emacs-keys.org             # global key table (executable, not docs)
nix/                       # overlays, recipes, node-packages
local-templates/           # source of truth for AI-agent configs
conf/                      # Xresources, sway/i3, dunstrc, qt5ct
scripts/                   # 80+ bash helpers
tests/                     # 4 categories (vm / contract / scenario / gui)
tools/                     # holo-verify, surface-lint, mkforce-lint
submodules/                # 11 git submodules (Emacs packages)
