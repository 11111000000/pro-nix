Соглашения

В репозитории нет формального RFC-процесса. Есть соглашения, которым должны следовать все — человек или агент. Каждое короткое, у него есть причина, и за ним как минимум один tests/contract/*-чек.

См. под-страницы ниже.

Под-страницы

  • Коммиты — формат тип: описание, список типов.
  • mkForce — три приоритета NixOS module system и когда какой использовать.
  • Change-Gate — формат PR body с Intent/Pressure/Surface/Proof.
  • Мёртвый код — детекторы и ритуал удаления.
  • Анти-паттерны — то, что в коде есть, но не стоит добавлять самому.

Куда смотреть

  • tools/holo-verify.sh — оркестратор тестов.
  • tools/surface-lint.sh — секции шапки + наличие кириллицы.

  • tools/docs-link-check.sh — сломанные внутренние ссылки.

  • tests/contract/unit/* — короткие shell-скрипты.

Страницы в этом разделе

  • Коммиты — Формат: тип: описание. Один коммит = одна логическая правка. Типы: nix, emacs, keys, fix, ops, site, chore.
  • mkForce — Три приоритета NixOS module system: plain (обязательно), mkDefault (по умолчанию), mkForce (per-host override). lib.mkDefault НЕ использовать для обязательных пакетов.
  • Change-Gate — Формат PR body: Intent / Pressure / Surface / Proof. [FROZEN] поверхности требуют migration notes. Валидируется actions/check-change-gate/action.sh.
  • Мёртвый код — Сигналы: placeholder, пустой systemPackages, mkIf false {}, sha256 0000, submodule без полей, enable = false default. Ритуал удаления: rg -l filename, rg attributeName, nix-instantiate --parse.
  • Анти-паттерны — То, что в коде есть, но не стоит добавлять самому. mkDefault для обязательных пакетов, hardcoded IP в ssh_config, глобальный zoom, tailscale.enable=true, nixos-rebuild switch в CI.
