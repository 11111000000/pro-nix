* Конвенция

- Источник истины: эта таблица. Парсер — `pro-keys.el`.
- Формат строки: =| Section | Key | Command | Note |=
- Префиксы уровня 1 (одиночные буквы): =C-c <letter>=.
- =s-= (Super) оставлен ТОЛЬКО для EXWM-секции — он работает под EXWM,
  под Gnome/Cinnamon отдаётся DE (Activities/workspace switch).
- Колонка Note содержит мнемонику (что значит буква после префикса).
- Все клавиши подобраны так, чтобы оставаться в домашнем ряду и не
  конфликтовать с DE/WM.
